# NovaCRM 3

Універсальна CRM для будь-якої компанії. Працює двома способами з одним і тим самим кодом:

| | Офлайн (флешка, один комп’ютер) | Сервер (уся команда) |
|---|---|---|
| Запуск | відкрити `NovaCRM.html` у Chrome або Edge | `node server/server.js` |
| Дані | один зашифрований файл `novacrm-data.json` | `data/db.json` на сервері + щоденні копії |
| Доступ | пароль бази | логіни, ролі: адміністратор, керівник, працівник, лише перегляд |
| Інтернет | не потрібен | у локальній мережі або через HTTPS |

**Розділи:** головна панель, календар, клієнти, угоди (воронка-дошка), об’єкти / проєкти (етапи, бюджет, витрати, баланс), задачі (дошка), рахунки й акти (оплати, прострочення), витрати, склад (прихід / списання на об’єкт), техніка (ТО), персонал, партнери (постачальники і субпідрядники), документи (файли всередині бази), звіти (прибутковість, дебіторка, воронка, витрати, завантаження персоналу, склад, клієнти — друк у PDF і експорт у Excel), журнал змін, налаштування.

**Під компанію:** назва, тип (будівельна / послуги і продажі), увімкнення й вимкнення розділів, власні назви розділів, кольорові теми (класична біло-коричнево-червона, графіт, синя, зелена або власні кольори). Демо-режим — будівельна компанія «БудМайстер» (вигадані дані).

**Безпека:** офлайн-файл шифрується AES-256-GCM, ключ з пароля через PBKDF2-SHA256 (600 000 ітерацій), автоблокування через 15 хв. На сервері — паролі scrypt, cookie HttpOnly + SameSite, обмеження спроб входу, перевірка прав на кожен запит, файли даних недоступні з браузера.

Детальна інструкція: [ІНСТРУКЦІЯ.html](ІНСТРУКЦІЯ.html).

## Розробка
Код — у `assets/js/*.js` (модулі). Після змін зберіть один файл для роботи з флешки:
```
python3 tools/build.py
```
