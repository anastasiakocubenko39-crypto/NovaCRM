NovaCRM — інструкція

Як почати роботу з флешки без інтернету, як встановити на сервер для всієї команди і як налаштувати програму під свою компанію.

1. Робота з флешки (без сервера й інтернету)

  1. Скопіюйте папку NovaCRM на флешку (бажано зашифровану — див. нижче).
  2. Відкрийте NovaCRM.html у Chrome або Edge (подвійний клік або перетягніть файл у вікно браузера).
  3. Натисніть «Створити нову базу»: вкажіть назву компанії, тип і пароль (від 8 символів). Збережіть файл novacrm-data.json у ту саму папку на флешці.
  4. Далі програма сама зберігає зміни в цей файл через 1–2 секунди після кожної дії (індикатор «Збережено» вгорі).
  5. Наступного разу: відкрийте NovaCRM.html → «Відкрити …» → пароль.
Забутий пароль = дані втрачено. Пароль ніде не зберігається, файл без нього не розшифрувати. Запишіть пароль у надійному місці.
Кнопка «Заблокувати» (замок угорі) зберігає зміни і закриває базу. Через 15 хв бездіяльності програма блокується сама (час можна змінити в налаштуваннях).

Додатковий захист флешки (рекомендовано)

Файл бази вже зашифрований. Щоб захистити ще й саму програму та інші файли, зашифруйте флешку безкоштовною програмою VeraCrypt (veracrypt.fr): Create Volume → Encrypt a non-system partition/drive → флешка → пароль → exFAT. Перед шифруванням скопіюйте все з флешки на комп’ютер — шифрування її стирає.

2. Встановлення на сервер (для всієї команди)

Потрібен комп’ютер або сервер у мережі компанії (Windows, Linux або macOS) з Node.js 18+ (nodejs.org). Додаткові бібліотеки не потрібні.

  1. Скопіюйте папку NovaCRM на сервер.
  2. Запустіть у цій папці:
    node server/server.js
  3. У консолі з’явиться логін admin і тимчасовий пароль — увійдіть з браузера за адресою http://IP-сервера:8080.
  4. У «Налаштування → Користувачі» додайте працівників із ролями і змініть пароль адміністратора.
РольЩо може
Адміністраторусе, включно з налаштуваннями, користувачами й імпортом
Керівник / менеджерстворювати, змінювати й видаляти записи в усіх розділах
Працівникбачить усе; додає й змінює задачі, документи, витрати; рухає склад
Лише переглядтільки читання

Параметри

PORT=8080 DATA_DIR=/var/lib/novacrm node server/server.js

Автозапуск на Linux (systemd)

[Unit]
Description=NovaCRM
After=network.target
[Service]
WorkingDirectory=/opt/NovaCRM
Environment=PORT=8080 DATA_DIR=/var/lib/novacrm
ExecStart=/usr/bin/node server/server.js
Restart=always
User=novacrm
[Install]
WantedBy=multi-user.target

Docker

docker build -t novacrm .
docker run -d -p 8080:8080 -v novacrm-data:/data --name novacrm novacrm
Якщо сервер доступний з інтернету, обов’язково ставте його за HTTPS (наприклад, Caddy або nginx із сертифікатом Let’s Encrypt). У локальній мережі офісу достатньо http.

Перенесення офлайн-бази на сервер

В офлайн-версії: «Налаштування → Експорт для серверної версії». На сервері під адміністратором: «Налаштування → Імпорт офлайн-бази». Файл експорту не зашифрований — після імпорту видаліть його.

3. Щоденна робота

  • Головна — об’єкти в роботі, воронка, борги клієнтів, витрати місяця, задачі і що потребує уваги (прострочені оплати, закінчуються матеріали, ТО техніки).
  • Угоди і задачі — дошка: перетягуйте картки між колонками. Коли угода «Виграно», програма запропонує створити об’єкт.
  • Об’єкти — етапи робіт, бюджет, фактичні витрати, виставлені й оплачені рахунки, баланс.
  • Рахунки й акти — кнопка «Внести оплату», автоматичний статус «Прострочено».
  • Склад — «Прихід» (з автоматичним записом у витрати) і «Списати» на об’єкт.
  • Пошук угорі (клавіша /) — по всіх розділах, телефонах, адресах.
  • Звіти — прибутковість об’єктів, дебіторка, воронка, витрати за статтями, завантаження персоналу, залишки складу, клієнти. «Друк / PDF» і «Excel (CSV)».

4. Налаштування під свою компанію

  • Тип компанії: «Будівельна компанія» (об’єкти, техніка, матеріали) або «Компанія послуг / продажів» (проєкти, товари, без техніки).
  • Розділи: вмикайте лише потрібні.
  • Назви: перейменуйте будь-який розділ (наприклад, «Об’єкти» → «Замовлення»).
  • Кольори: класична тема (білий, коричневий, червоний), графіт, синя, зелена або власні кольори.
  • Значення за замовчуванням для нових баз — у файлі config.js.

5. Резервні копії

  • Флешка: щотижня копіюйте novacrm-data.json в інше місце або натискайте «Налаштування → Резервна копія». Копія теж зашифрована.
  • Сервер: програма щодня сама кладе копію в data/backups і зберігає 30 днів. Додатково копіюйте папку data на інший диск.
